# 台湾市场特例（只在做台湾 deck 时读）

完整口径以 `deliverables/taiwan-pan-entertainment-stablecoin-mpc-20260817/README_台灣數娛版_口徑與決策.md` 为准。本文件只是摘要。

## 为什么是特例

8 月去台湾出差时，带去的 deck 客户听不懂，原因有两个：

- 行业不同：台湾数娱老板不是币圈人，"机构钱包""托管""KYT"这些词对他们来说是空的。
- 用词不同：大陆的"结算""风控"在台湾不是同一个意思。

所以台湾版要用台湾用语、繁体，并且每个概念都要换成老板日常会说的话。

## 定位

- MPC：Cobo MPC｜面向玩家的自建穩定幣充提平台
- Payment：Cobo Payment｜企業級穩定幣網銀平台。用"网银"做比喻：像用企業網銀一樣，收、付、管理穩定幣
- 封面：數娛平台穩定幣收付方案／玩家充提 × 企業收付

## 用词表

| 不用 | 改用 |

| 機構、機構錢包、企業錢包 | 企業 |
| 通道、支付網關（用来说自己时） | 網銀平台、技術服務商 |
| 結算、交收 | 收付、對帳、付款與出金 |
| 風控 | 簽核、出款管控 |
| 提幣 | 提領 |
| KYT、AML、Screening（单独使用时） | 髒U篩查（KYT）；假U辨識 |
| C 端、用戶 | 玩家（直播、社交场景可临时换成「用戶」） |
| 創建、支持 | 建立、支援 |
| U 盾 | 憑證 |
| 回 call | 回呼 |

## 台湾专用说法

- 回答"私钥不在我手上"：你用企業網銀，銀行也不會把金庫鑰匙給你，但每一筆錢出去，都要你的憑證加上你們內部簽核。
- 「放不放行你說了算」（用于 MPC 的自订髒U门槛）
- 「平台你自己建，底層交給 Cobo」「AI 能幫你寫出第一版，但第 1,000 天出事的時候，要有人扛。」
- 「為什麼不用通道？」：資金直接進你的帳戶／出款權在你手上／新加坡總部，合規經營，沒有跑路風險
